## templjs v1.0.0-beta.1: TypeScript Meta-Templating System

templjs v1.0.0-beta.1 is now available as a beta release.

### What’s New

- TypeScript-native parser/AST architecture
- Schema-aware template authoring and validation
- CLI workflows for rendering and validation
- VS Code + Volar integration foundations
- Documentation and examples expanded for production onboarding

### Why It Matters

templjs helps teams generate consistent structured output (Markdown, HTML, JSON, YAML, TOML, XML) from validated data models with predictable template behavior.

### Get Started

```bash
npm install @templjs/core@1.0.0-beta.1
npm install -D @templjs/cli@1.0.0-beta.1
```

Read the docs:
